DOCUMENTO FUNCIONAL TML STOCK
Versión 1.0
1. Objetivo del sistema
El sistema tiene como objetivo controlar el flujo completo de producción y stock de TML.
No pretende ser un ERP general ni administrar clientes, proveedores, compras, contabilidad o facturación.
Su único objetivo es registrar el movimiento físico de la mercadería desde que se corta la tela hasta que el producto es vendido o transferido entre depósitos.
El sistema está diseñado para reflejar exactamente la forma de trabajo actual de la empresa, intentando modificar la menor cantidad posible de procesos internos.
2. Filosofía del sistema
El sistema es un sistema de movimientos.
No trabaja sobre "procesos abstractos", sino sobre operaciones reales que realizan los empleados todos los días.
Cada operación genera automáticamente los movimientos de stock correspondientes.
El usuario solamente informa qué ocurrió.
El sistema calcula el resto.

4. Tipos de productos existentes
Durante el análisis se identificaron seis grupos completamente distintos.
1. Productos Base
Son productos que todavía no pueden venderse.
Ejemplos:
Cortadas de trapos
Rollos de rejilla
Productos comprados sin etiqueta
Se utilizan para abastecer talleres o iniciar procesos internos.
2. Productos Comerciales
Son todos los productos que pueden venderse.
Se almacenan por depósito.
Pueden venderse:
Unidad
Docena
Fardo
según lo indique cada producto.
Cada producto comercial define:
marca
medida
cantidad por fardo
si requiere taller
si requiere etiquetado
3. Productos Fallados
Son productos devueltos por los talleres que presentan defectos.
No se enfardan.
Siempre se almacenan individualmente.
También generan pago al taller.
4. Retazos
Son sobrantes obtenidos durante el corte.
No representan desperdicio.
Se almacenan porque posteriormente pueden reutilizarse para realizar nuevas cortadas.
Se registran únicamente para mantener consistencia del stock físico.
5. Insumos
Se controlan únicamente de forma manual.
No se descuentan automáticamente.
Su objetivo es generar alertas cuando el stock sea bajo.
Actualmente se registran:
Conos de hilo
Hilo de enfardar
Bolsas
6. Talleres
Los talleres representan producción externa.
No son depósitos normales.
Cada taller posee:
stock propio
tarifas
producción
pagos
5. Depósitos
Actualmente existen siete depósitos.
Zona de Corte
Aquí permanecen:
cortadas
retazos
fallados
fardos abiertos para venta minorista
Es el punto de inicio de toda la producción.
Galpón Central
Contiene:
productos terminados embolsados.
Casa
Contiene principalmente:
insumos
franelas
rejillas
paños
repasadores
Contenedor
Depósito destinado al excedente de producción.
Puede contener cualquier producto.
Galpón Secundario
Aquí permanecen generalmente los bultos comprados a proveedores.
Depósito Eve
Depósito perteneciente al taller de Evelina.
Puede contener excedentes.
Depósito Vanesa
Depósito perteneciente al taller de Vanesa.
Puede contener excedentes.
6. Reglas fundamentales
Estas reglas surgieron directamente del funcionamiento de la empresa.
Regla 1
Una cortada nunca puede venderse.
Regla 2
Toda cortada debe pasar por un taller.
Regla 3
El taller devuelve:
productos comerciales
fallados
Nunca devuelve cortadas.
Regla 4
Los fallados siempre permanecen en unidades.
Nunca se enfardan.
Regla 5
Los fallados también generan pago al taller.
Cuando exista una tarifa por fardo, el sistema calculará automáticamente el valor unitario:
Tarifa fardo / 60

9. Reglas de Negocio y Validaciones
Este apartado reúne todas las reglas que deben cumplirse obligatoriamente durante el funcionamiento del sistema.
Estas reglas representan la operatoria real de TML y no deben modificarse sin autorización, ya que forman parte del modelo de negocio de la empresa.
9.1 Reglas Generales
RN001
Una cortada nunca puede venderse.
Siempre debe pasar previamente por un taller.
RN002
Todo producto comercial vendido debe existir previamente en stock.
No se permiten ventas con stock negativo.
RN003
Los productos fallados nunca pueden venderse.
Únicamente permanecen almacenados en la Zona de Corte.
RN004
Los retazos nunca generan productos automáticamente.
Su registro tiene únicamente fines de control de stock.
RN005
Los insumos se administran manualmente.
El sistema no realizará descuentos automáticos por consumo.
RN006
Todos los movimientos registrados generan automáticamente una actualización del stock.
No existen movimientos sin impacto sobre el inventario.
RN007
Cada movimiento posee un identificador único y permanente.
No podrá reutilizarse.
RN008
Una vez confirmado un movimiento no podrá modificarse.
En caso de error deberá realizarse un Ajuste de Stock o un nuevo movimiento correctivo.
9.2 Cortadas
RN009
Todas las cortadas ingresan inicialmente al depósito "Zona de Corte".
RN010
Las cortadas únicamente pueden enviarse a un taller.

No existe control por lotes ni trazabilidad individual de las cortadas.

18.2 Glosario
Producto Base
Producto intermedio que aún no puede venderse y requiere pasar por un proceso posterior.
Producto Comercial
Producto listo para su comercialización.
Producto Fallado
Producto devuelto por un taller que presenta alguna falla, pero cuya producción debe computarse para el pago correspondiente.
Retazo
Fragmento de tela recuperado durante el proceso de corte y reutilizado posteriormente para fabricar nuevas cortadas.
Cortada
Conjunto de piezas cortadas listas para enviarse a un taller.
Taller
Lugar donde se realiza la costura de las cortadas o la confección de rejillas.
Entrega
Movimiento mediante el cual se envían productos base desde la fábrica hacia un taller.
Devolución
Movimiento mediante el cual un taller devuelve productos terminados y fallados.
Transferencia
Movimiento de stock entre depósitos.
Ajuste
Corrección manual realizada sobre el stock cuando existe una diferencia física.
